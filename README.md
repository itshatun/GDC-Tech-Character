# 🎮 Tech Character

A simple interactive game developed for the Game Development Club.

## 💡 About

Tech Character is a short quiz that discovers the player's
technical personality based on their answers.

At the beginning, the player enters their name and major.
After answering 7 questions, they receive a Tech Identity Card
with their technical character and skills.

## 🎮 How to Play

1. Enter your name.
2. Enter your major.
3. Answer 7 questions.
4. Discover your Tech Character.
5. View your Tech Identity Card.

## ✨ Features

- Arabic and English languages
- Interactive questions
- Different technical characters
- Personalized Tech Identity Card
- Simple game animations
- Responsive design

## 💻 Technologies

- CSS
- JavaScript
